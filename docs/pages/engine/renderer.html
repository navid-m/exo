project_to_screen

pub fn project_to_screen(view_proj: math.Mat4, point: math.Vec3) ScreenProjection

Project a world-space point into screen UV space for full-screen effects such as godrays. The origin is the top-left of the render target. visible is false when the point is behind the camera or so far outside the viewport that a screen-space effect would no longer be meaningful. Off-screen light sources are allowed, which lets shafts enter from the edge of the frame.

apply_post_process

pub fn apply_post_process(runtime_raw: ref void, settings: postprocess.PostProcessSettings, enabled: bool, time: f32) bool = trust { ... }

Run the engine post-process stack and leave the swapchain pass open so UI can be drawn on top. The engine owns the implementation; games only provide generic PostProcessSettings. When godrays are enabled this convenience wrapper assumes a light near the upper middle of the screen; use apply_post_process_with_light to supply an exact projected light position.

apply_post_process_with_light

pub fn apply_post_process_with_light(runtime_raw: ref void, settings: postprocess.PostProcessSettings, enabled: bool, time: f32, light_screen_x: f32, light_screen_y: f32, light_visible: bool) bool = trust { ... }

Run the engine post-process stack with an explicit screen-space light position. light_screen_x/light_screen_y are in UV space with the origin at the top left. The godray pass is skipped when light_visible is false or the light is behind the camera.
